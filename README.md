# mi-repo

Repositorio de prueba para practicar el flujo de Pull Requests con GitHub.

## Primeros pasos

1. Clona este repositorio:
   ```bash
   git clone https://github.com/rodriguezbusiness999-dev/mi-repo.git
   ```
2. Crea una rama para tus cambios:
   ```bash
   git checkout -b mi-rama
   ```
3. Haz tus cambios, confirma y abre un Pull Request.

## Flujos de WhatsApp

En la carpeta [`whatsapp/`](whatsapp/) hay un proyecto para **enviar mensajes de
WhatsApp** con la Cloud API oficial de Meta. Empieza por la guía paso a paso:
[`whatsapp/GUIA.md`](whatsapp/GUIA.md).
